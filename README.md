# EcoCycle

EcoCycle là nền tảng web giúp kết nối cộng đồng trong lĩnh vực thu gom, phân loại và tái chế phế liệu/rác thải, hướng tới xây dựng lối sống xanh và bảo vệ môi trường. Dự án lấy cảm hứng từ các nền tảng như metycle nhưng hướng tới nâng cấp trải nghiệm người dùng, mở rộng tính năng cộng đồng và gamification, đồng thời tối ưu UI/UX.

## 🚀 Tính năng nổi bật

- **Đăng tin mua/bán phế liệu, rác thải**  
  Người dùng có thể đăng tin, tìm kiếm và liên hệ với các đối tác uy tín.

- **Bản đồ điểm thu gom**  
  Tích hợp Google Maps giúp tra cứu vị trí các điểm thu gom/tái chế gần nhất.

- **Quản lý giao dịch**  
  Theo dõi lịch sử giao dịch, trạng thái đơn hàng, đánh giá đối tác.

- **Kiến thức về vật liệu & tái chế**  
  Thư viện kiến thức về phân loại rác, quy trình tái chế, mẹo bảo vệ môi trường.

- **Blog & cộng đồng**  
  Chia sẻ kinh nghiệm, tổ chức sự kiện, thử thách, đóng góp ý tưởng bảo vệ môi trường.

- **Gamification**  
  Hệ thống điểm thưởng, huy hiệu cho người dùng tích cực, bảng xếp hạng cộng đồng.

- **Đăng nhập/xác thực bảo mật**  
  Hỗ trợ đăng nhập qua mạng xã hội, OTP, phân quyền người dùng.

## 💡 Điểm vượt trội dự kiến so với metycle

- Cộng đồng sôi động hơn qua các event, diễn đàn, thử thách hàng tháng.
- Thống kê tác động môi trường thực tế của từng người dùng.
- Tích hợp AI nhận diện vật liệu qua ảnh (sắp ra mắt).
- Tính năng dành cho doanh nghiệp: Quản lý nhiều điểm thu gom, báo cáo tự động.

## 🛠️ Công nghệ sử dụng

- Frontend: JavaScript/ReactJS (hoặc NextJS)
- Backend: NodeJS/ExpressJS
- Database: MongoDB/MySQL
- API: Google Maps, OpenAI (AI phân loại rác)
- UI/UX: Material UI, Ant Design

## 🚀 Hướng dẫn cài đặt & chạy dự án

```bash
# Clone dự án
git clone https://github.com/Logm12/EcoCycle.git
cd EcoCycle

# Cài đặt dependencies
npm install

# Chạy ứng dụng
npm start
```
